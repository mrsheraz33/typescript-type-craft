# TypeScript Types and Unions

This repository contains my TypeScript practice code for learning type aliases and related concepts.

## Topics Covered

* Type Aliases
* Primitive Type Aliases
* Array Type Aliases
* Intersection Types (`&`)
* Union Types (`|`)
* Enums
* Literal Types

## Concepts

### Type Aliases

Used to create custom types for objects, primitive values, arrays, and more.

### Intersection Types

Combine multiple types into a single type using `&`.

### Union Types

Allow multiple possible data types using `|`.

### Enums

Used to define a set of named constants.

### Literal Types

Allow only specific predefined values and are commonly used instead of enums in modern TypeScript.
